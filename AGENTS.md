# AttestPay

Agentic spending cards: scoped, revocable payment delegations that any AI agent can plug in and pay

Package manager: bun.

## Commands

- dev: `bun dev`
- test: `bun test`
- typecheck: `bun typecheck`

## Layout

- `contracts/`
- `docs/`
- `harness-privy/`
- `packages/`
- `probes/`

## Rules

- Run `bun test` before you say a change is done.
- Never commit secrets or `.env` files.
